# AI Usage

AI tools were used as development assistance tools during this project.

Claude Code was used in VS Code primarily for:

- brainstorming and refining implementation approaches
- assisting with project scaffolding and code structure
- suggesting implementation patterns for the backend workflow
- helping write and improve automated tests
- debugging issues identified during development
- reviewing code for edge cases and potential failures
- assisting with documentation such as README.md and DECISIONS.md

The overall problem-solving approach, architecture, policy decisions, guardrail
design, feature selection, testing strategy, and final implementation
decisions were directed and reviewed by the developer.

AI-generated suggestions were reviewed, tested, and modified where necessary
before being integrated into the project. They were used only when they matched
the requirements of the problem and the supplied data pack.

The developer is responsible for understanding, testing, and explaining the
submitted code and design decisions.
