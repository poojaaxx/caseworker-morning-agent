# AI Usage

AI tools were used as a development assistance tool during this project.

Claude Code was used in VS Code primarily for:
- brainstorming and refining implementation approaches
- assisting with project scaffolding and code structure
- suggesting implementation patterns for the backend workflow
- helping write and improve automated tests
- debugging issues identified during development
- reviewing code for edge cases and potential failures
- assisting with documentation such as README.md and DECISIONS.md

The problem-solving approach, architecture, policy decisions, guardrail design,
feature selection, testing strategy, and final implementation decisions were
reviewed and directed by the developer.

AI-generated suggestions were reviewed, tested, modified where necessary, and
integrated only when they matched the requirements of the problem and data pack.

The developer is responsible for understanding and explaining the submitted
code and design decisions.
